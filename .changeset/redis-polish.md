# Redis panel: hash, list, sorted-set and set cells can be edited in place (double-click or F2, Enter saves, Esc cancels; a hash field name, a zset score or member too, renames run in one MULTI). The string editor has Save and Revert buttons, a "Modified" marker and Ctrl+S, and keeps the TTL. The key list can be resized by dragging its edge (the width is remembered), long key names show in full in a tooltip, and the slow log lists the newest entry first.
